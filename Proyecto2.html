Casa de 3 niveles

El proyecto consistió en diseñar y configurar una red para una casa de 3 niveles, realizando diferentes tipos de conexiones en cada piso para lograr que todos los dispositivos pudieran comunicarse correctamente. En el primer nivel se configuró un router conectado de manera inalámbrica a 2 computadoras y una impresora, permitiendo que los dispositivos tuvieran acceso a la red sin utilizar cables. En el segundo nivel se conectaron 3 computadoras y 3 laptops a un switch mediante conexiones cableadas, y posteriormente el switch fue conectado al router para brindar acceso a internet y comunicación entre los equipos. En el tercer nivel se utilizó un access point para conectar inalámbricamente 3 tablets y 3 laptops. Después, el access point fue conectado al switch para extender la red hacia el último nivel de la casa. Gracias a esta configuración, los 3 niveles quedaron interconectados y funcionando correctamente, permitiendo una comunicación estable entre todos los dispositivos de la red.

Tablas de datos

El proyecto 3 consistió en trabajar con bases de datos en MySQL utilizando phpMyAdmin. Durante el desarrollo del proyecto creamos varias tablas de datos y realizamos las conexiones entre ellas para que pudieran relacionarse correctamente mediante claves y relaciones. Después de crear las tablas, verificamos que todas las conexiones funcionaran correctamente observando el diagrama de la base de datos en phpMyAdmin. Al generarse el diagrama correctamente, comprobamos que las relaciones entre las tablas estaban bien estructuradas y organizadas. Además, realizamos pruebas ingresando datos dentro de las tablas para asegurarnos de que la base de datos funcionara de manera correcta y que la información pudiera almacenarse sin errores. Con este proyecto aprendimos a diseñar, relacionar y administrar bases de datos de forma más ordenada y funcional.

Usuarios y publicaciones

El proyecto 4 fue muy similar al proyecto anterior, ya que también trabajamos con bases de datos en MySQL y phpMyAdmin realizando conexiones entre diferentes tablas. Sin embargo, la diferencia fue que en este proyecto utilizamos una mayor cantidad de tablas y agregamos más funciones para que el sistema fuera más completo e interactivo. Entre las funciones implementadas estaban la opción de dar “like”, comentar en publicaciones y otras características relacionadas con la interacción de los usuarios dentro del sistema. Todas las tablas fueron relacionadas correctamente para que las funciones trabajaran de manera adecuada y la información pudiera almacenarse sin errores. Además, verificamos el funcionamiento mediante el diagrama en phpMyAdmin y realizando pruebas ingresando datos en cada una de las tablas para confirmar que todo funcionara correctamente.

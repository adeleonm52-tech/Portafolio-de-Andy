Sitio Web Portafolio con proyectos de Semestre

Durante el desarrollo del proyecto se realizaron varios incrementos y mejoras con el propósito de construir una página web más completa, organizada y funcional. A lo largo del proceso se trabajó en diferentes etapas, agregando nuevas características, diseños y contenidos para mejorar la presentación y el funcionamiento del sitio web. Asimismo, se llevaron a cabo investigaciones relacionadas con el diseño, estructura y herramientas necesarias para la elaboración de la página web, permitiendo aplicar correctamente los conocimientos adquiridos. Finalmente, se logró presentar una página web 100% funcional, capaz de mostrar correctamente toda la información, imágenes, videos y proyectos desarrollados durante el curso.
